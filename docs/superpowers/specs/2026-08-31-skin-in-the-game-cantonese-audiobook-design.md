# 《非对称风险》粤语有声书设计

## 目标

把源 EPUB《非对称风险：风险共担，应对现实世界中的不确定性》制作成完整、适合长时间收听的香港粤语有声书。成品保留作者的论证、事实、数据、例证、限定条件及原有章节顺序，不改写成摘要或讲书版。

## 范围

- 保留：推荐序 1、推荐序 2、译序、第一卷绪论的三个篇章、第 1 至 19 章、后记、致谢和附录 1 至附录 3。
- 不制作：版权页、注释、参考书目。
- 每一个上述原书篇章或章节生成一份阅读稿及一个最终 MP3；不因篇幅拆分或合并。
- 各卷标题只记录为章节归属，不生成单独音轨。

## 交付结构

输出目录为 `非对称风险/`：

- `Script/`：人工可读的香港粤语阅读稿；允许用 `/` 标示轻停顿。
- `TTS/`：由阅读稿生成的纯文本合成稿，以及书籍专用发音词典 `pronunciation-dictionary.tsv`。
- `Audio/`：按播放顺序编号命名的最终 MP3；所有最终音频验证成功后才生成 M3U。
- `README.md`：记录源文件、章节清单、声音、语速、生成日期、时长、词典替换、未解决读音与播放列表路径。

## 文本与声音规范

- 阅读稿采用约 70% 香港粤语口语、30%书面表达，语气平静、专业、适合知识节目。
- 不添加评论，不删减实质内容，不把不确定说成确定。
- TTS 使用 `zh-HK-WanLungNeural`，语速 `+20%`，输出 MP3。
- TTS 副本应用内置词典及书籍专用词典；必须应用 `噉` 到 `咁` 的替换，并在合成前确认零个字面 `/`。

## 流程与验收

1. 从 EPUB 的导航目录与 HTML 正文提取确认的内容边界。
2. 逐篇改写阅读稿，完成粤语质量检查；阅读稿不因发音处理而覆盖。
3. 生成独立 TTS 文本，检查发音词典格式、替换结果及斜线安全性。
4. 选择代表性正文制作约一分钟试听，并用 `ffprobe` 验证媒体属性；用户确认试听前不批量合成。
5. 获确认后生成全部最终 MP3，逐个检查非空、格式、时长、采样率、码率与文件大小。
6. 所有预期 MP3 均通过验证后，生成 UTF-8、以 `#EXTM3U` 开头的 M3U；逐项检查路径、数量和顺序。

## 异常处理

- 如果词典格式错误、术语无法安全处理，暂停该项并记录原因，不更换引擎或声音。
- 批量合成中断时保留已有非空且通过验证的 MP3，后续仅继续缺失文件。
- 任一最终章节未完成或验证失败时，不创建或刷新最终 M3U。
