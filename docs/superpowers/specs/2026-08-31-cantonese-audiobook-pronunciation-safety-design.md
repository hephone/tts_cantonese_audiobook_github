# 粤语有声书繁体与读音安全设计

## 目标

强化 cantonese-audiobook-generator，使其输出的阅读稿和 TTS 稿均为香港繁体，并在合成前阻断会导致粤语模型误读的输入。成语、固定搭配、术语、书名和引用句保持规范书面语，不作逐字口语化。

## 适用范围

- 修改 .agents/skills/cantonese-audiobook-generator/SKILL.md、其内置发音词典、规范化脚本及现有评测用例。
- 不改变原书的观点、信息边界、章节映射、声音选择或播放列表规则。
- 不把已有书籍的未审核全文自动覆写；每本书的 Script 和 TTS 输出依照新规则逐篇生成。

## 文本策略

1. 完成粤语句法编辑后，将阅读稿转为香港繁体；以 OpenCC s2hk 再次转换而内容无变化作为通过条件。
2. 从通过的阅读稿生成独立 TTS 文本；词典应用、斜线清理后，TTS 文本也必须通过同样的繁体检查。
3. 成语、固定搭配、书面术语、专有名词、书名和引文维持规范书面写法。例如保留「不請自來」，不机械改为「唔請自來」。
4. 对单字或短语的读音风险，优先选择自然且语义等价的繁体表达。例如使用「海龜」「一齊」「食曬佢」「推畀人」，避免依赖不稳定字形或多音字。

## 合成前安全门槛

以下任一项失败时，不执行 edge-tts：

- 书籍或内置词典不是合法 UTF-8 TSV，或出现空源词、空替换、冲突条目、源词等于替换词。
- TTS 文本包含字面 /。
- Script 或 TTS 文本经 OpenCC s2hk 后仍会变化。
- 显式检测到已登记的不稳定写法，且没有经过安全改写。

## 纠错闭环

试听发现错误后，记录原写法、实际错误读法、替换方式和原因。优先改写受影响的 TTS 短语；如需要，人审阅读稿同步采用自然繁体表达。只重制受影响 TTS 文件和 MP3，之后重跑繁体、斜线和 ffprobe 验证。

## 验收

- 规范化工具能拒绝可转换的简体输入，并给出清晰文件路径和原因。
- 词典解析保留现有长词优先、一次替换和零斜线行为，并拒绝无效的同值条目。
- 评测覆盖：简体「海龟」、成语「不請自來」、稳定替换「一齊／食曬佢／推畀人」、畸形 TSV 和字面 /。
- 现有「噉 → 咁」强制替换继续生效。
